# Asnor Ali — Cinematic Portfolio

A cinematic, mobile-first personal portfolio for Asnor Ali.

## Included
- Hero / introduction
- Personal story
- Selected work
- Capabilities
- Technology toolkit
- Services
- Direct email inquiry form
- Responsive mobile layout
- Scroll reveal animations
- Subtle grain/noise
- Magnetic interactions
- Reduced-motion support

## No backend required
The inquiry form uses `mailto:` so the visitor's email client opens with the inquiry prepared.

## Before publishing
Replace every occurrence of:

`YOUR_EMAIL@example.com`

with your real email address.

## Run locally
Open `index.html` directly, or serve the folder with any static web server.

## Deploy
This is static and can be deployed to GitHub Pages, Vercel, Netlify, or another static host.
